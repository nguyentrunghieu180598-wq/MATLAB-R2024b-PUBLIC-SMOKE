# Privacy policy — JTE BTMS RESEARCH (personal research tool)

This Google Cloud OAuth client is used only by its owner (the owner of this GitHub repository) for a personal academic research project on battery thermal management simulations.

- Scope requested: `https://www.googleapis.com/auth/drive.file` only. The tool can access only the files and the folder that it creates itself in the owner's Google Drive. It cannot read any other Drive files.
- Data stored: simulation outputs and verification receipts, written by automated GitHub Actions runs to a private folder owned by the owner.
- No data is shared with, sold to or disclosed to any third party. No analytics and no advertising.
- No other users: the app is not offered to the public.
- Deletion: the owner can delete the folder at any time in Google Drive and revoke access at https://myaccount.google.com/permissions .
- Contact: open an issue in this GitHub repository.

Last updated: 3 November 2026.
